# Category artwork originals

Local PNG source copies of the 11 AI-generated AutoMall category illustrations. These files are intentionally ignored by Git and kept outside `app/public/` so Vite cannot include them in the deployed site. Native originals are also preserved in Codex's generated-images library.

The deployed 1000 × 667 WebP derivatives live in `app/public/assets/categories/`. Prompts and visual verification are documented in `refs/category-art-prompts.md`.
